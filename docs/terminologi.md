# Terminologi

Fælles ordliste for oversættelsen, tjekket mod dansk fantasy-litteratur, danske spil og opslagsværker (2. oktober 2026).
Brug den, når du retter i Manageren, så de samme engelske ord altid bliver til de samme danske.

| Engelsk | Dansk | Begrundelse / kilde |
|---|---|---|
| spell | **besværgelse** | De danske Harry Potter-bøger bruger *besværgelse* om navngivne trylleformler: *Afvæbningsbesværgelsen* (Expelliarmus), *Lammebesværgelsen* (Stupefy), *Skjoldbesværgelsen* (Protego). Dansk Magic: The Gathering-materiale kalder også spells *besværgelser*. *Trylleformular* betyder strengt taget selve ordene/remsen (lex.dk). |
| curse / cursed | **forbandelse / forbandet** | HP: *Dræberforbandelsen*, *forbandelser*. |
| wizard | **troldmand** (flertal *troldmænd*) | HP (*troldmænd og hekse*), *Troldmanden fra Jordhavet*, dansk rollespil (Troldmand/Heks). |
| mage | **magiker** | Danske rollespilsregler (Mager/Magiker). Bruges kun hvor spillet siger *mage*. |
| archmage (rang) | **Ærketroldmand** | Den danske Jordhavet-oversættelse bruger det litterære *Ærkekogleren*. Det er for gammeldags til en spilmenu, så vi følger *troldmand*. |
| cast (a spell) | **kaste** (en besværgelse) | Almindeligt i dansk fantasy (*kaste en forbandelse*). |
| the caster | **du / dig** | Danske spiltekster taler direkte til spilleren (fx Minecraft på dansk). *Kasteren* lyder oversat. |
| summon | **fremmane** | Det klassiske danske ord for at kalde noget frem ved magi. HP's *hidkalde* (Accio) betyder at kalde noget *hen til sig* og passer ikke her. |
| conjure | **fremmane** | Som ovenfor. |
| invoke | **påkalde** | lex.dk sætter besværgelse i familie med *påkaldelse*. |
| charm (HP-fag) | Besværgelser | Hogwarts-faget hedder *Besværgelser* på dansk (Flitwick). |
| potion / tonic | **eliksir** | HP-faget *Eliksirer*. Den danske Minecraft-guide hedder *Guide til fortryllelse og eliksirer*. |
| enchantment | fortryllelse | Minecraft på dansk (bruges ikke i MageQuit lige nu). |
| shield | **skjold** | HP: *Skjoldbesværgelsen*. |
| petrify | **forstene** | Almindeligt dansk. |
| fireball | **Ildkugle** | Danske rollespilsregler (Sydsjællands Rollespil). |
| melee | **nærkamp** | Danske rollespilsregler. |
| damage / health | **skade / liv** | Danske Magic: The Gathering-regler. |
| knockback | **tilbageslag** (et tilbageslag: *højt* tilbageslag) | Intet etableret spilord. Intetkøn, så *højt*, ikke *høj*. |
| cooldown | **nedkøling** | Bruges i danske spiloversættelser. Mange danske spillere siger bare *cooldown*. |
| ability | evne | Dansk spiljournalistik (geekd.dk). |
| draft (spells) | udvælgelse | Intet etableret ord. Ret gerne, hvis familien har et bedre. |
| element | element | |
