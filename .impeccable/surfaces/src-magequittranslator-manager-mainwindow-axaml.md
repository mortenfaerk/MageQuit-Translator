# MageQuit Translator app (Avalonia desktop)

Mode: Operate. Two jobs share one window: players pick a language and play (Book home);
translators edit a language beside the running game (the Spread).

## Direction contract

THESIS: A bilingual facing-page spellbook. English incantation on the verso, the translation on the recto, each line sealed when reviewed. It refuses the sidebar-plus-grid localisation tool.

OWN-WORLD: Night-violet binding (#1b1230), plum vellum pages (#2b1d48), chalk ink (#efe7ff), gilt (#e8c25a) only for the one primary action and reviewed seals, element inks (fire #ff6b3d, water #3fa7ff, nature #7ed957, electric #f5e14a) for chapters. Fixed seal legend: hollow ring unsealed, pencil-grey dash draft, gilt disc sealed. Thumb-index tabs sized by chapter extent; ribbon bookmarks per language.

STORY: A player sees their language, presses Play in it, and is done. A translator opens the spread, works chapter by chapter, sees each line's length budget and font proof, seals it, and exports the language for a pull request.

FIRST VIEWPORT: Left, the frontispiece: language ribbons stacked like bookmarks, the active one long. Centre, the game's menu words in the label font, flipping letter by letter into the chosen tongue. The gilt action "Play in Dansk" sits under them. Top right: the install state as one line.
